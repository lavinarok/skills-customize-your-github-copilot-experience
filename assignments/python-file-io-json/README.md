# 📘 Assignment: Python File I/O and JSON

## 🎯 Objective

Learn how to read and write files in Python and work with JSON data. This assignment helps students practice storing information, loading saved data, and using real-world file formats in small programs.

## 📝 Tasks

### 🛠️ Read and Display Data from a File

#### Description
Create a program that reads data from a text file and prints it to the screen. This will help you understand how Python can access saved information from the filesystem.

#### Requirements
Completed program should:

- Open a text file using Python file operations
- Read the file contents
- Display the contents clearly in the terminal
- Handle the case where the file does not exist gracefully

### 🛠️ Write a New File

#### Description
Build a simple script that creates a new file and writes user input into it. This exercise focuses on saving information for later use.

#### Requirements
Completed program should:

- Ask the user for a few pieces of information
- Create a new file with a meaningful name
- Write the data into the file
- Confirm that the file was written successfully

### 🛠️ Work with JSON Data

#### Description
Use Python's JSON module to save and load structured data. This introduces the idea of storing lists and dictionaries in a readable, reusable format.

#### Requirements
Completed program should:

- Store data in a Python dictionary or list
- Convert the data to JSON using `json.dumps()`
- Save the JSON data to a `.json` file
- Load the saved JSON data back into Python and print it
- Show the data in the same structure that was originally created

### 🛠️ Build a Small Project

#### Description
Combine file reading, writing, and JSON into a small real-world project such as a note taker or a simple contact list.

#### Requirements
Completed program should:

- Let the user add entries to a list
- Save the data to a JSON file
- Reload the data when the program starts
- Display the saved data in a clear format
- Keep the program easy to run and understand
